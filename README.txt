# Leilão de Futebol com Pausa Global pelo Anfitrião

## Funcionalidades Atualizadas:
1. **Pausa Global Real**: O anfitrião tem um painel exclusivo com o botão **"⏸️ Pausar Leilão"**. Ao acionar, o cronômetro trava e o leilão para instantaneamente para **todos** os participantes conectados.
2. **Modal Tático Automático**: Um pop-up gigante aparece na tela de todos mostrando o status de Pausa Global, a **Média de Overall** do time, a contagem de titulares e acesso direto à escalação e banco de reservas.
3. **Retomada Controlada**: O anfitrião pode clicar em **"▶️ Retomar Leilão"** para que a disputa volte a fluir normalmente para todos.
